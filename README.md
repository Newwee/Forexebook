# SMC Warriors Trader - Interactive Forex Ebook Learning Platform

แพลตฟอร์มการเรียนรู้ Forex และ Smart Money Concepts (SMC) แบบ Interactive ที่พัฒนาและถอดรหัสจากเนื้อหาทั้งหมด 116 หน้าของ `Trade.pdf` (SMC Warriors Trader E-Book)

---

## ฟีเจอร์หลัก (Key Features)

- **16 บทเรียน SMC ครบวงจร:** ครอบคลุมตั้งแต่ผู้เล่นในตลาด, โครงสร้างตลาด (Market Structure), Demand & Supply, Valid Pullback (Advance), BOS, IDM (Inducement), CHoCH, MSS, Liquidity (BSL/SSL), Order Flow, Order Blocks (OB), Single Candle OB (SCOB), Breaker Blocks (BB & BRK), POI, Fair Value Gap (FVG), Fibonacci Premium/Discount ไปจนถึงจิตวิทยาการเทรดและพิมพ์เขียว Model Entry 5 สเต็ป
- **ระบบแบบทดสอบเชิงลึก (Interactive Quizzes):** มีแบบทดสอบประจำบทพร้อมเฉลยละเอียด ทำไมคำตอบที่ถูกจึงถูกตามกลไกสถาบัน และทำไมตัวเลือกอื่นจึงเป็นกับดัก พร้อมเกณฑ์ผ่าน 80%
- **ห้องทดลองจำลองสถานการณ์จริง (Scenario Simulator):** แบบฝึกหัดตัดสินใจจากกราฟจริง 6 เคสการเทรด
- **คลังคำศัพท์ Forex & SMC (Searchable Glossary):** รวม 36 คำศัพท์สถาบัน เช่น Pip, Spread, Lot, Leverage, Margin, Stop Loss, Take Profit, IDM, FVG, SCOB พร้อมตัวอย่างและการเชื่อมโยงบทเรียน
- **ระบบบันทึกความก้าวหน้า (Progress & Memory):** บันทึกประวัติบทเรียนที่จบ, คะแนน Quiz, จุดอ่อนที่ต้องทบทวน, Streak การเรียนรู้, บุ๊กมาร์ก และสมุดจดบันทึกส่วนตัว
- **ออกแบบเพื่อ iPad และ Tablet (iPad-First Experience):** รองรับ Safe Area, Touch Target ขนาดไม่ต่ำกว่า 44px, ป้องกัน Horizontal Overflow, ธีม Dark Navy และสีเขียวมรกต (Emerald Green) ระดับ FinTech

## เทคโนโลยีที่ใช้ (Tech Stack)

- **Frontend:** React 18, TypeScript, Tailwind CSS, Vite
- **Icons:** Lucide React
- **Typography:** Inter, Sarabun, JetBrains Mono
- **State & Storage:** React Context API + LocalStorage Persistence

---

## วิธีการติดตั้งและรันโปรเจกต์ (Getting Started)

### 1. ติดตั้ง Dependencies
```bash
npm install
```

### 2. รันโหมด Development
```bash
npm run dev
```
เปิดเบราว์เซอร์ไปที่ `http://localhost:3000`

### 3. Build สำหรับ Production
```bash
npm run build
npm run preview
```
